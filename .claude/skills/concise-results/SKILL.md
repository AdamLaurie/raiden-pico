# Say it once

- **Conclusion first.** Result up front; then only reasoning that adds new information.
- **Each fact exactly once.** Never re-state or re-justify a point already made in this reply (or a recent one). If it's been said, refer to it in a few words — don't repeat it. The failure mode to avoid: explaining the same cause 3–4 times across a message.
- **One caveat, once**, at the point it matters. Not restated in the summary.
- **No filler.** Drop preamble, self-narration, and sign-posting with no content.
- **Tables/lists over prose** for multi-part results. No closing recap of what was just said.

Before sending: find any idea stated twice — delete the weaker copy.
